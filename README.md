# toptradecall
Develop a TradingView multiple and single timeframe indicator which calls buy or sell alerts that have a high possibility to follow analysis and share a chance for a trader to confluence with his/her analysis.

## Top Trade Calls indicator suite

See [`indicators/Top Trade Calls/`](indicators/Top%20Trade%20Calls/) for the
Pine Script v6 indicator suite: a base single-timeframe script, one script
per timeframe (1m through 1W), and a multi-timeframe dashboard. All original
code -- see that folder's README for how the scoring works and how to add
the scripts to TradingView.
